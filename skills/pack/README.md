# The Marketing Skill Pack

The actual AI skills I use to find and fix the revenue hiding inside a business —
packaged so you can run them yourself.

Six skills, two ways to use them:

1. **As Claude skills** — drop each folder into your Claude skills directory and
   invoke it by name. (Power-user route.)
2. **As copy-paste prompts** — open `PROMPTS.md`, copy the one you want, paste it
   into Claude or ChatGPT, and go. (Works anywhere, no setup.)

## What's inside

| Skill | What it does |
|---|---|
| **Funnel Leak Finder** | Point it at your numbers → ranked list of where you're leaking revenue, in dollars, with the fix for each. |
| **Offer Sharpener** | Scores your offer on the value equation and rebuilds the weak parts — promise, proof, guarantee, price, name. |
| **Hook & Ad Writer** | Generates and *scores* ad creative — video scripts + static/paid-social copy — on a 14-point rubric before you spend a dollar. |
| **Landing Page Critic** | A prioritized CRO teardown of any page: the biggest leaks first, each with the reason and a rewrite. |
| **Masterclass Funnel Architect** | Designs or audits a webinar/masterclass funnel end to end — page, script, emails, offer — using market-awareness + mechanism-naming. |
| **Content & Teardown Writer** | Writes a sharp, teachable teardown-style post or newsletter that reads like one operator talking to another. |

## How to install as Claude skills

Copy any skill folder into `~/.claude/skills/`, then start a new Claude session.
Invoke with the skill name (e.g. "run the funnel leak finder on these numbers").

## How to use the prompts

Open `PROMPTS.md`, copy a prompt, paste it into a fresh Claude or ChatGPT chat,
answer the questions it asks, and it runs.
